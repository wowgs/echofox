# 4. Что переделать (предложение)

## Сервер

- Реестр адаптеров вместо списка в коде: встроенные плюс найденные в папке плагинов; грузятся только включённые в конфиге.
- Без включённых адаптеров `context` не вызывается вовсе: текст перед звуком — только промпт.
- Метрики и `adapter.json` записи: какой адаптер, версия плагина.

## Приложение

- Снимок фокуса и включение дерева Electron — только для приложений включённых адаптеров (сейчас дерево включается у любого Electron-приложения, которое стало активным: VS Code, Slack и другие тратят на него ресурсы зря). Включать при запуске такого приложения и при старте Local Voice; при активации — как страховку (повторное включение стоит 0,45 мс, медиана 20 прогонов, Claude Desktop, 15 октября).
- Раздел «Адаптеры» в окне настроек (шаг 4 плана первой версии).

## Конфиг

- `adapters: {"<имя>": {"enabled": bool, "hash": "<хеш файлов при подтверждении>"}}`.
- Версия конфига растёт до 3; сервер переводит версию 2 сам.

## Документы

- Основной документ: требования (базовый режим, необязательные адаптеры, плагины), HLD (слой адаптеров, разрешения) — когда решения здесь устоятся.

## Порядок

1. Базовый режим и включение адаптеров в конфиге (без плагинов): встроенные адаптеры выключаемы, дерево Electron только для включённых.
2. Плагины из папки и манифест.
3. Изоляция стороннего кода — после выбора варианта.
