# 1. Идея

Рабочий документ: как перестроить Local Voice так, чтобы адаптеры стали необязательными, а сторонние разработчики могли писать свои. Когда решения устоятся, они переезжают в основной документ «Local Voice: product design» ([ссылка](../design/1-what-and-why.md)), вкладки 2 и 4, а этот документ уходит в архив.

## Решение Алекса (15 октября)

- **Базовый режим — без адаптеров.** Приложение работает сразу после установки: диктовка через Gemma с базовым промптом и языком, который выбрал пользователь. Контекста разговора нет.
- **Адаптер — необязательная добавка.** Пользователь включает адаптер для своего приложения (Claude Desktop, Claude Code в терминале, Codex …), и диктовка в это приложение получает контекст разговора: последние ответы и термины. Качество растёт.
- **Адаптеры пишут и другие.** Адаптер — плагин в папке; кто угодно может написать свой, положить туда или подключить с чужого GitHub.
- **Сторонние плагины — дело пользователя.** Приложение открытое; наше приложение и наши плагины подписаны и нотаризованы; что пользователь подключает со стороны, он подключает сам и на свою ответственность. Ограничивать и изолировать сторонние плагины не будем.

## Оценка (предложение)

- **За.** Продукт полезен с первой минуты, без настройки, на любом приложении. Адаптеры — понятная причина остаться: «включи для Claude — станет точнее». Сторонние адаптеры дают покрытие приложений, которое мы сами не напишем.
