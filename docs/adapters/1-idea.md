# Зачем нужны адаптеры

Адаптер добавляет к диктовке контекст приложения: недавние сообщения, имена и термины. Без адаптеров EchoFox тоже распознаёт речь и вставляет текст.

Это документ о решениях по устройству продукта. Поддерживаемые приложения, формат плагина и команды проверки описаны в [справочнике адаптеров](../reference/3-context.md).

## Решения

Решения от 15 октября 2026, с уточнением состояния на 25 октября:

- **Адаптер необязателен.** Отсутствие подходящего плагина или точного совпадения с разговором не мешает обычной диктовке.
- **Одна платформа — один плагин.** Пути, форматы транскриптов и правила конкретного приложения остаются внутри его плагина. Ядро не содержит логики отдельных поставщиков.
- **Контекст выбирается по текущему окну.** Самая новая сессия не обязательно та, в которую человек диктует. При неоднозначности контекст не используется.
- **Доступ виден пользователю.** Манифест перечисляет приложения, файлы и нужные данные экрана. Дерево Electron и дополнительные данные экрана запрашиваются по потребностям включённых адаптеров.
- **Приватная диктовка обходит адаптеры.** Приложению остаётся только определить поле для вставки; снимок контекста на сервер не передаётся.
- **Сторонние плагины выполняются с правами пользователя.** Проверка манифеста и версии интерфейса не является изоляцией кода.

Контекст может помочь распознать термины, но величина улучшения пока не подтверждена сравнением на размеченном наборе. В описании продукта не следует обещать, что любой адаптер обязательно повышает точность.

## Что уже работает

Встроенные плагины `claude` и `telegram`, загрузка пользовательских плагинов из папки, включение через настройки и перезагрузка при изменении файлов. Текущая версия интерфейса — 2.

Встроенные и пользовательские плагины имеют одинаковую структуру: `adapter.json` и `adapter.py`. Пользовательский плагин с именем встроенного заменяет его. Значения контекста задаёт манифест; пользователь меняет их в записи своего адаптера в конфиге.

## Что остаётся предложением

- Установка по ссылке на GitHub и каталог плагинов в приложении.
- Подсказка включить адаптер, когда обнаружено подходящее приложение.
- Показ источника контекста последней диктовки в меню.
- Плагины на других языках через отдельный процесс, если появится такая потребность.
- Новые адаптеры: Codex, ChatGPT, Antigravity, Gemini и Telegram Web.

## История перехода

15 октября встроенный список Python-модулей заменили реестром плагинов. Конфиг версии 3 добавил явное включение адаптеров; последующие версии перенесли параметры контекста к каждому адаптеру. Сейчас используется конфиг версии 7.

Старый план переделки выполнен в основной части и больше не нужен как отдельная инструкция. Текущий контракт хранится в справочнике, дальнейшие задачи — в [плане работ](../ideas.md).
