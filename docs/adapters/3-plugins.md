# 3. Адаптеры как плагины

## До переделки (факт)

Адаптеры были модулями Python в `server/adapters/`, список был зашит в коде. Каждый — класс `Adapter` с тремя обязательными методами: `claim` (моё ли это и с какой уверенностью), `context` (найти разговор), `clean` (сделать из текста приложения ровную прозу). Ядро спрашивает всех, отдаёт запись самому уверенному, чистит сообщения его `clean` и считает термины по очищенному тексту.

## Решение (Алекс, 15 октября)

- **Папка плагинов:** `~/Library/Application Support/Local Voice/adapters/<имя>/`. Встроенные плагины лежат внутри приложения и выглядят так же. Один плагин — одна платформа: `claude` (Claude Desktop, Claude Code), дальше так же OpenAI (Codex, ChatGPT) и Google (Antigravity, Gemini). Всё, что касается одной платформы — её файлы, форматы, поля, — живёт в её плагине; ядро не знает ни одного вендора (решение Алекса, 15 октября).
- **Плагин = манифест + модуль.** `adapter.json`: имя, версия, автор, ссылка на исходники, для каких приложений (bundle id), что читает (пути), нужно ли дерево Electron, версия интерфейса адаптеров. `adapter.py`: класс-наследник `Adapter`. Папка плагина — пакет Python, поэтому `adapter.py` может подключать свои модули.
- **Подключение.** Положить папку плагина или дать ссылку на репозиторий GitHub — приложение скачает его в папку плагинов. Плагин включает пользователь в настройках; там же видно, что плагин о себе говорит в манифесте. Включённые — в конфиге (`adapters: {"<имя>": {"enabled": true}}`).
- **Сторонние плагины — на ответственности пользователя** (решение Алекса, 15 октября): приложение их не ограничивает и не изолирует. Проверяем только базовое: манифест читается, версия интерфейса подходит, модуль загружается и в нём есть класс `Adapter`.
- **Адаптер — для любого приложения, где есть то, о чём пишут:** чат с ассистентом, мессенджер (Telegram), почта, документ, терминал; не только сессии с агентами. Интерфейс версии 2: `claim(focus, hints)` → уверенность или ничего; `context(focus, hints)` → `about` (что это, для модели: «a Telegram chat with Anna»), `messages` [{`from`, `text`}] от новых к старым, `terms` (свои имена места), `source` и `details` (только для записи); `clean(text)`. `focus` — снимок фокуса, `hints` — что знает клиент, ядро их не читает.
- **Интерфейс стабилен и версионирован.** Меняется интерфейс — растёт его версия; плагин старой версии не грузится, а в настройках сказано почему.
- **Ядро, а не адаптер, решает, когда включать дерево Electron и делать снимок:** по манифестам включённых адаптеров.
