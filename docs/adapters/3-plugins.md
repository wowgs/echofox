# 3. Адаптеры как плагины

## Сейчас (факт)

Адаптеры — модули Python в `server/adapters/`, список зашит в коде (`ADAPTERS`). Каждый — класс `Adapter` с тремя обязательными методами: `claim` (моё ли это и с какой уверенностью), `context` (найти разговор), `clean` (сделать из текста приложения ровную прозу). Ядро спрашивает всех, отдаёт запись самому уверенному, чистит сообщения его `clean` и считает термины по очищенному тексту.

## Предложение

- **Папка плагинов:** `~/Library/Application Support/Local Voice/adapters/<имя>/`. Встроенные адаптеры (Claude Desktop, Claude Code) лежат внутри приложения и выглядят так же.
- **Плагин = манифест + модуль.** `adapter.json`: имя, версия, автор, ссылка на исходники, для каких приложений (bundle id), что читает (пути), нужно ли дерево Electron, версия интерфейса адаптеров. `adapter.py`: класс-наследник `Adapter`.
- **Включение — только руками пользователя,** в настройках, после показа манифеста. Включённые — в конфиге (`adapters: {"<имя>": {"enabled": true}}`). Новый или изменённый плагин (другой хеш файлов) снова выключен, пока пользователь его не подтвердит.
- **Интерфейс стабилен и версионирован:** ядро передаёт снимок и названные клиентом сессии, адаптер возвращает уверенность и сообщения. Меняется интерфейс — растёт его версия; плагин старой версии не грузится, а в настройках сказано почему.
- **Ядро, а не адаптер, решает, когда включать дерево Electron и делать снимок:** по манифестам включённых адаптеров.

## Открытые вопросы

- **Изоляция стороннего кода.** Плагин на Python в процессе сервера получает все права пользователя: читает любые файлы, ходит в сеть. Варианты: каждый плагин — отдельный процесс без сети (`sandbox-exec` устарел, но работает — не проверено; или песочница App Sandbox для отдельного помощника); только чтение путей из манифеста; только проверенные плагины из каталога. Выбор — после разбора вариантов.
- **Язык плагинов.** Python — как сервер; другие языки — через процесс с протоколом (JSON по stdin/stdout). Нужно ли — открыто.
- **Каталог.** Где брать плагины: только папка, или ещё список в репозитории проекта.
