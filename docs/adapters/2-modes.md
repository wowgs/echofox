# 2. Базовый режим и адаптеры

## Что работает в каком режиме (решение Алекса, 15 октября)

| Что | Базовый режим | С адаптером приложения |
|---|---|---|
| Горячая клавиша, запись, распознавание Gemma | да | да |
| Язык и промпт | выбор пользователя | выбор пользователя |
| Текст перед звуком | только промпт | контекст разговора, потом промпт |
| Вставка: поле нажатия, иначе поле в конце, иначе вставка туда, где курсор, если приложение ничего не говорит о своём поле, иначе буфер обмена | да | да |
| Снимок фокуса (окно, элемент, родители, процессы) | нет | только в приложениях включённых адаптеров |
| Дерево Accessibility у Electron-приложения (`AXManualAccessibility`) | нет | только у приложений включённых адаптеров |
| Чтение файлов приложения (транскрипты, хранилище сессий) | нет | только то, что объявил адаптер |

## Разрешения macOS

- **Микрофон** — всегда.
- **Accessibility** — всегда: клавиша и вставка. Без него приложение работает в урезанном виде: запись по клавише-сочетанию, текст в буфер обмена. Делать ли такой урезанный режим — открытый вопрос.
- **Доступ к файлам** — нужен ли отдельный запрос macOS (Full Disk Access или доступ к папкам) для файлов адаптеров, не проверено: сейчас сервер читает `~/.claude` и `~/Library/Application Support/Claude` без запросов, но он запущен агентом launchd, а не из песочницы.

## Что видит пользователь (решение Алекса, 15 октября; делается вместе с новым UI, позже)

- Первый запуск: микрофон, Accessibility, модель — и диктовка работает везде.
- Окно настроек, раздел «Адаптеры»: список найденных адаптеров, у каждого — для каких приложений, что читает (из его манифеста), переключатель. Найдено приложение, для которого есть адаптер (например, установлен Claude Desktop), — подсказка «включить адаптер для Claude Desktop».
- В меню у последней диктовки — был ли контекст и от какого адаптера.
