# 1. What and why

Local Voice — приложение для macOS: диктовка локальной моделью Gemma 4 прямо на Маке, в любом приложении, с учётом того, о чём идёт разговор. Документ на 15 октября 2026: что и зачем, требования, ограничения и архитектура (HLD). Выбор технологий — отдельным шагом, после архитектуры.

Связанные документы:

- [Dictation terms](../dictation-terms/1-untitled.md): словарь терминов.
- [Local Voice: optional adapters](../adapters/1-idea.md): рабочий документ — необязательные адаптеры и адаптеры-плагины; решения оттуда переедут сюда.
- [Local Voice: LoRA training](../lora-training/1-idea.md): дообучение модели распознавания на размеченных записях пользователя, на его Маке.

## Что

- Нажал горячую клавишу в любом поле ввода, сказал, нажал ещё раз — текст вставлен туда, где стоял курсор.
- Распознаёт модель на самом Маке: Gemma 4 E4B в llama.cpp. Звук не уходит в облако.
- Модель знает контекст разговора: адаптер целевого приложения находит разговор, в который идёт текст, и подкладывает модели последние ответы и термины из него.
- Всё ставится и настраивается из самого приложения: сервер, модели, клавиша, промпт.

## Зачем

- **Приватность.** Звук и текст не покидают Мак.
- **Смешанная речь.** Русская речь с английскими терминами, где облачная диктовка путает термины. Что контекст разговора улучшает распознавание по сравнению с облачной диктовкой Anthropic, пока не измерено; это предположение, которое продукт должен подтвердить.
- **Везде одинаково.** Одна диктовка в Claude Desktop, VS Code, терминале и любом другом приложении.
- **Продукт.** Выложить публично и продвигать как «ваша локальная Gemma, работает с Claude».

## Адаптеры

Адаптер — модуль под одно целевое приложение. Он знает, как найти разговор, в который сейчас диктуют, и как из этого разговора построить контекст для модели. Первый адаптер — Claude Desktop. Его вкладка Code пишет разговоры в `~/.claude/projects`, как и другие клиенты Claude Code (расширение VS Code, CLI). Следующие — например Codex, Antigravity, ChatGPT, Telegram.

## Решения Алекса

- Продукт для macOS, который можно выложить публично и продвигать (15 октября).
- Диктовка на уровне ОС, в любом приложении, без вмешательства в целевые приложения (14–15 октября).
- Адаптеры к целевым приложениям; каждый определяет, откуда и как строится контекст. Первым делаем решение для Claude Desktop, потом дописываем адаптеры (15 октября).
- Модели — из каталога, который мы поддерживаем; сейчас Gemma 4 E4B в двух квантованиях, Q8\_0 и Q4\_0 (15 октября).
- Приложение ставит всё нужное само. Сервер — внутри пакета приложения; модель пользователь загружает из UI. Сборки: без модели и с каждой из моделей каталога (15 октября).
- Сервер диктовки остаётся бэкендом; UI его не заменяет, а вызывает (15 октября).
- Сессию адаптер находит только точно, по окну с курсором; угадывания нет, при неудаче — без контекста (15 октября).
- Клавиша — переключатель, без удержания; настраивается в UI. По умолчанию — простое нажатие, не занятое ни системой, ни Claude, ChatGPT и Antigravity; какое именно, исследуем позже, пока подойдёт любое удобное (15 октября).
- Разговор на экране: ядро в момент нажатия делает снимок фокуса и отдаёт запись тому адаптеру, который увереннее всех признал снимок своим; сессию и контекст находит этот адаптер (15 октября).
- Индикатор записи у текстового курсора — если API позволяет сделать его аккуратно (15 октября).

## Предложения

- **Для кого.** Люди, которые на Маке работают с AI-ассистентами голосом и говорят смешанной речью: русский с английскими терминами.
- **Что не делаем.** Облачное распознавание; Windows и Linux; распознавание в реальном времени с текстом по ходу речи — текст приходит после стопа, кусками.
