# Ограничения и наблюдения

Эта страница объясняет, какие ограничения повлияли на архитектуру. Числа ниже — наблюдения на конкретной машине и версиях программы, а не обещания для всех Mac.

## Машина разработки

Замеры октября 2026 выполнены на Apple M5 с 10 ядрами GPU, 24 ГБ памяти и macOS 27.0.1. Использовался `llama-server` 0.6.0, сборка 11429 (`d81235049`), с Metal.

Файл Q8_0 занимает около 8,0 ГБ, Q4_0 — 4,6 ГБ; общий аудиопроектор BF16 — ещё 0,99 ГБ. Полный размер загрузки включает проектор.

## Память

19 октября у Q8_0 около 7,6 ГБ весов были отображены из файла через mmap. macOS может освободить чистые страницы и позднее прочитать их с диска. Это не означает, что модель перестаёт влиять на доступную память.

Собственная память процесса после запуска составляла около 0,66 ГБ. С включённым кэшем промптов на 8 ГиБ она за 27 часов выросла до 8,85 ГБ; система использовала swap. Поэтому отдельный RAM-кэш отключён: `--cache-ram 0`.

На той же машине в одном наблюдении были заняты 23 из 24 ГБ памяти и 9,2 ГБ swap. Это состояние рабочего компьютера, не минимальное требование приложения.

## Ограничения распознавания

| Наблюдение | Следствие |
|---|---|
| В текущем каталоге Gemma принимает до 30 секунд аудио за запрос. | Длинные записи нужно делить. |
| В журналах используемой сборки llama.cpp аудиовход отмечен как экспериментальный. | Обновления движка требуют проверки на записях. |
| В выборке из 2038 кусков все 35 почти без речи давали выдуманный текст или копировали контекст. | Перед моделью нужен детектор речи. |
| В метриках 18–19 октября генерация занимала 78% ожидания после стопа для записей из одного куска; медиана — 21 токен/с. | Оптимизацию нужно оценивать по задержке и качеству на нашем наборе. |
| Генерация иногда не останавливается вовремя. | Сервер ограничивает длину ответа и отбрасывает результат при достижении лимита. |

## Доступ к целевым приложениям

Приложению нужны разрешения Microphone и Accessibility. Через Accessibility оно определяет поле ввода и вставляет текст; адаптеры используют доступные метаданные окна.

Исторические наблюдения, которые нужно перепроверять при обновлении целевых приложений:

- Claude Desktop отдавал поле ввода только после включения `AXManualAccessibility` (15 октября).
- Claude Desktop, Telegram и Ghostty не отдавали пригодную позицию текстового курсора. Для индикатора можно использовать рамку окна.
- Транскрипт Claude Code сам по себе не доказывает, что именно эта сессия открыта. Нужна связь с текущим окном.
- Codex Desktop возвращал ошибку −25205 при попытке включить дерево Accessibility (18 октября). Это наблюдение одной версии, а не постоянное ограничение платформы.

Local Voice не меняет пакеты целевых приложений. Их внутренние форматы, включая хранилище сессий Claude, могут измениться без предупреждения.

## Перед публичным выпуском

Проверить условия распространения модели Gemma, подпись Developer ID, нотаризацию и установку на чистом Mac. Это открытые задачи, а не подтверждение готовности к выпуску. Состояние упаковки и проверок — в [распространении](7-distribution.md).
