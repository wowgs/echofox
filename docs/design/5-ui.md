# Интерфейс и настройки

Диктовка запускается клавишей. Меню даёт доступ к частым действиям, а окно настроек — к остальным параметрам. Инструкция для пользователя находится в [справочнике приложения](../reference/4-app.md); здесь объясняется устройство интерфейса.

Требования: FR-2, FR-10–FR-13 и NFR-5 в [требованиях](2-requirements.md).

## Строка меню

Значок показывает ожидание, запись, обработку или ошибку. Обычная запись обозначается красным микрофоном, приватная — фиолетовым.

Порядок пунктов:

1. **Разрешения**, пока хотя бы одного не хватает. Невыданное разрешение открывает System Settings; выданное видно неактивной галочкой.
2. **Микрофон и громкость входа.** Используется системная громкость macOS.
3. **Label Recordings…** — разметка.
4. **Settings… (⌘,)** — настройки.
5. **Quit Local Voice.**

Порядок задаёт `SettingsLayout.menu`, отображение — `MenuBar.swift`. Живой индикатор уровня рядом с громкостью остаётся предложением.

## Сочетания клавиш

По умолчанию правый Option переключает обычную диктовку, правый Command — приватную. Срабатывает отдельное нажатие и отпускание клавиши; обе клавиши меняются на странице General.

Соседняя клавиша даёт приватному режиму такой же жест без задержки на ожидание двойного нажатия. Приватный режим не запускает адаптеры и не отправляет снимок контекста; поле для вставки определяется локально.

Конфликты с другими приложениями возможны. Надёжный способ обнаружить чужие привязки ещё не выбран. Наблюдение 18 октября о голосовой функции Claude Desktop на правом Command относится только к проверенной тогда версии.

## Окно настроек

| Страница | Содержимое |
|---|---|
| General | Клавиши, остановка по тишине, предел записи. |
| Microphone | Микрофон и громкость; пробная запись и уровень сигнала пока предложены. |
| Language | Язык, примечания к промпту, удаляемые запинки. |
| Model | Модель, вариант, промпт, папка моделей, загрузка и удаление; сэмплинг в Advanced. |
| Adapters | Раскрываемая группа с отдельной страницей каждого адаптера: состояние, разрешённые источники и параметры контекста. |
| Recordings & Labels | Сохранение и папки данных, сведения о разметке. |
| Diagnostics | Сервер, выбранная модель и диагностические сведения; состояние обновляется каждые 2 секунды, пока страница открыта. |

History появится только после реализации истории диктовок. Сейчас это не существующая страница.

Окно запоминает последнюю страницу и раскрытые разделы. Значение поля применяется по Return или при потере фокуса. Advanced расположен внизу страницы и раскрывается нажатием на всю строку заголовка.

### Значения по умолчанию и сброс

У настройки есть значение компонента по умолчанию и необязательная правка пользователя. Сброс удаляет правку из конфига. Значение, равное значению по умолчанию, не считается изменённым.

Это правило одинаково для счётчика «2 changed», кнопки сброса и подписи «Set here.». Оно реализовано в `SettingStore.swift`.

Пустое числовое поле показывает значение по умолчанию серым. Рядом остаётся единица измерения; допустимый диапазон показывается при неверном вводе, например «Enter a number from 5 to 30.».

## Как устроены настройки

![Сервер и приложение описывают настройки, приложение определяет расположение и строит интерфейс.](img/5-ui-settings.svg)

Описание настройки отделено от её расположения. Синим показано приложение, оранжевым — сервер, серым — конфиг; пунктир показывает запись значений.

- **Смысл и тип:** сервер отдаёт настройки сервера, моделей и адаптеров в `info`. Настройки приложения описаны в Swift.
- **Расположение:** `SettingsLayout.swift` задаёт страницу, раздел и порядок. Новая серверная настройка без отдельной строки размещается по своему компоненту и группе.
- **Хранение:** окно изменяет одно значение в `~/.local-voice/config.json`, сохраняя оформление файла через `JSONEdit.swift`. Сервер подхватывает изменения автоматически.

Неверные серверные настройки записываются в журнал и заменяются значениями по умолчанию. Расширенный показ этих ошибок в Diagnostics остаётся предложением.

### Схема описания настройки в ответе `info`

Контракт полей `key`, `owner`, `kind`, `default`, `value`, границ и справки описан в [протоколе](../reference/6-protocol.md#server-information). Не дублируем его здесь, чтобы схема не расходилась между страницами.

Константы сервера в список редактируемых настроек не входят. У каждого адаптера свои значения `context`, у языка — `notes` и `fillers`, у модели — шаблон `prompt`.
